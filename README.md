# AI Navigators — Meeting 1 Slides

شرائح اللقاء الأول من ورشة «الكتابة الهادفة بالذكاء الاصطناعي» — «بوصلة الاستهداف».

Interactive slides website for AI Navigators Meeting 1 (Targeting Compass), in Egyptian Arabic, RTL.

## What's inside

- 11 slides, matching the unified live script (00:00–90:00)
- Every station and content block opens an explanation popup taken from the live script
- Autoplay (30s) with play/pause, animated transitions, progress bar
- Phone-friendly: tap / swipe / keyboard navigation, fullscreen
- Self-contained single `index.html` — no build step, no dependencies
